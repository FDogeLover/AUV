# D题 AprilTag＋蓝框融合视觉伺服

2026-07-30完成中心AprilTag身份确认、蓝色外框高频定位和RDK持续视觉追踪的首轮实飞闭环。

- **关键发现**：1.5 m只观察悬停的有效检测率为98.0%，观测约10.09 Hz。2026-07-30相对误差P闭环实飞最终确认X方向正确、Y方向相反：目标由`(452,139)`向上边缘发散，T265同时记录约0.46 m位移。当前映射为`error_x=320-cx`、`error_y=cy-240`。
- **影响范围**：`CyberCamera/boards/cybercam_d/`融合检测与VS1 flags；`drone_control/competition_2026_d/`视觉伺服、下降期间持续接管和测试安全边界；`docs/competition_2026_d/`协议与分工计划。
- **后续动作**：实飞验证静态相对误差P闭环在目标接近中心时及时制动、不再飞过头；小车T265到位后优先测试纯双T265低速直线伴飞，精度不足时再加入视觉相对位置修正。

当前策略是正确Tag只负责建立身份，蓝框负责主要中心定位，Tag光流负责颜色短时失效回退；颜色和光流都不能独立确认身份。运行时不再用固定0.5 m接管点软围栏阻止正常追踪，专项测试仅保留0.8 m紧急半径，最终伴飞改用场地或赛道边界。

持续下降实飞已验证1.5 m接管并下降到1.0 m，但旧`PlatformTracker`把静态画面变化估计成目标世界速度，造成无人机飞过目标后丢失。静态专项已移除世界目标速度估计和视觉速度前馈，改为3帧相对误差中值、按高度换算、直接P控制。Y轴翻转后的实飞曾精确到达`(320,239)`，证明XY符号正确，后续远离属于低阻尼过冲；当前降振参数为`Kp=0.35`、限速0.06 m/s、加速度0.15 m/s²、jerk 1.0 m/s³，视觉失效0.3秒后严格归零并交回T265保持。

降振实飞仍显示往复；飞控水平命令到T265实际速度的相关峰值滞后约1.2～1.4秒，航向变化仅约-3°～+3.6°。因此在相对位置P项上增加T265实际速度阻尼`-Kd*v_t265`，`Kd=0.50`；不使用视觉像素差分，也不恢复视觉目标速度估计。

T265阻尼实飞把后半段平均误差降至39.9 px、P90降至56.1 px、50 px内占比提高到73.3%，但零命令时T265实际速度中位数仍有0.044 m/s。当前已改为位置死区内继续D制动，只有位置误差≤0.05 m且水平速度≤0.02 m/s才判定居中；移动目标可靠完整观测限速提高到0.15 m/s，`PARTIAL_COARSE`仍限速0.06 m/s。

无目标速度前馈的移动目标实飞只能勉强追踪。临时测试现加入固定小车速度`(0.00,+0.10) m/s`，使用`v_platform + Kp*e + Kd*(v_platform-v_drone)`并保持总限速0.15 m/s；只适用于T265 `+Y`匀速直线，视觉丢失时仍原地保持，后续必须由小车实时速度或双T265替换固定值。

固定前馈移动专项统一在1.5 m高度进行：Tag确认后保持1.5 m伴飞20秒，不下降到1.0 m，不因居中3秒提前结束。1.0 m及以下高度留给后续投放和动态降落测试。

地图到位后固定`+Y 0.10 m/s`前馈已暂停，运行配置恢复平台速度零值。新增不连接飞控的`t265_map_point_recorder.py`，拆桨人工按`H→A→B→C_IN→C_OUT→D→H`测点，每点3秒中值/波动/置信度并保存CSV和原始JSONL，返回H自动计算闭环误差；连续三圈后重新初始化复测。

首轮人工测绘H/A/B有效，分别为`(0,0)`、`(0.364,0.812)`、`(0.319,2.289)`m；C入口处T265在3秒内虚假移动约13.84 m、最高速度5.26 m/s，随后置信度0，C无效。工具已增加标准差/静止速度/采样跨度/相邻点跳变硬门禁，灾难性漂移自动结束整轮。置信度2不能单独作为坐标有效依据。
