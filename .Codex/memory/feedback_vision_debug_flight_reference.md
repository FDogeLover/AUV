# 视觉调试必须基于真实飞行参照

## 用户经验

视觉算法的参数不能只靠台架画面或主观感觉调整，必须优先获取真实飞行状态下的
相机素材，再用这些素材做离线复现、阈值调整和回归验证。

## 执行约定

1. 固定点位视觉检测：先完成定点飞行和自动拍照，获得真实距离、姿态、振动、
   曝光和背景下的图片素材，再调整检测参数。
2. 长距离航行中的检测：按明确的时间或距离频率保存沿途图片，确保能还原漏检、
   误检发生前后的视觉上下文。
3. 拍照留档必须有独立调试开关；调试时开启，正式任务默认关闭，避免磁盘写入、
   编码开销和 I/O 抖动影响飞行任务。
4. 每张调试图片应尽量关联时间戳、任务状态、航点、位置、姿态、航向、检测结果
   和关键阈值；图片和飞行 JSONL 日志使用可对齐的时间基准。
5. 参数修改要用已归档的真实飞行素材做离线回放，并保留误检/漏检样本，不能只
   挑选成功图片验证。

## 对测试流程的影响

视觉功能的标准顺序为：路径与定点飞行验证 → 调试拍照采集 → 离线标注/调参 →
离线回放测试 → 视觉只读实飞 → 视觉控制实飞。没有真实飞行参照素材时，不应把
视觉参数宣称为已完成或可用于比赛。
