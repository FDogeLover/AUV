# T-018 蓝色方块1.5米视觉采数实飞

2026-07-29完成Cyber Camera外接CSI蓝色方块实飞采数，航线为 `1.5m → 0.15m → DESCEND/LAND`。

- **关键发现**：Cyber Camera约37.7 FPS，VS1共12428帧且CRC错误、序号缺口均为0；1.4m以上约16.3秒的识别率约39.9%。目标平均位于 `(509,443)`，227个有效检测中约225帧下边缘出画，因此问题是初始相对位置和部分出画，不是1.5m下目标尺寸不足。
- **飞行结果**：最终0.15m航点采用0秒停留和20秒下降超时，到达后未再等待15秒，DESCEND/LAND正常完成，最终解锁状态0且电机PWM归零。1.5m观察点以总超时推进，说明观察计时仍可能被航段总超时打断。
- **坐标约定**：当前外接CSI画面左方为无人机 `+X`，画面上方为 `+Y`；图像中心 `(320,240)`，控制误差使用 `320-cx`、`240-cy`。
- **影响范围**：`CyberCamera/boards/cybercam_d/`调试图片记录、`drone_control/basic/`最终航点停留策略、`docs/competition_2026_d/`视觉与无人机控制计划。
- **后续动作**：增加接触图像边框时的蓝色方块 `PARTIAL` 粗定位；固定1.5m做低速XY闭环。控制采用中值+alpha-beta滤波、10～15px死区、0.10～0.12m/s限速、0.3m/s²加速度限制和不超过0.15秒的短时预测，避免把像素抖动直接传给飞机。

调试图片记录已验证可按1 Hz生成标注JPEG；正式运行默认关闭。视觉预测只补偿处理延迟和极短漏检，不允许长时间盲追。
