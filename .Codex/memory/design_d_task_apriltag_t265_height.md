# D题中心AprilTag与T265高度策略

2026-07-29，根据官方答疑和现有传感器链路，确定D题视觉定位与高度控制的下一阶段简化方案。

- **关键发现**：官方允许在小车平台增加AprilTag、二维码或彩色方向标志；A点以车头到线为准；伴飞高度允许降低。当前采用一个贴在降落圆盘中心的AprilTag作为主定位，双圆环和十字保留。无人机固定机头时，小车转向不影响中心Tag的相对位置有效性。
- **高度决策**：T265 Z轴可避免激光照到抬高圆盘后引起的高度阶跃，但现有日志的`pos[2]`已被激光覆盖，不能证明T265高度精度。先验证T265原始Z，再决定是否采用“T265世界高度主控、激光近地辅助”。验证通过前不得拆除激光或将T265设为唯一高度源。
- **影响范围**：`docs/competition_2026_d/`视觉、无人机、小车和协议计划；后续Cyber Camera AprilTag检测、Pi/RDK高度源选择与飞行日志。
- **后续动作**：实现中心单Tag检测和VS1预留标志；增加T265原始/滤波Z日志；完成地面阶梯、60～120秒悬停漂移和等高板激光阶跃测试。

单Tag方案中，Tag中心与降落中心重合，因此暂不引入多Tag ID传输和安装偏移旋转。Tag航向保留用于诊断和转弯识别，无人机不跟随小车偏航。若中心贴纸遮挡十字交点，当前开发阶段不把十字当作完整备份，正式赛前再确认中心贴法。若以后增加多Tag或偏置安装，必须升级为VS2并显式传输目标类型和Tag ID。
