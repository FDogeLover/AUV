# T-017 T265与激光高度实飞结论

2026-07-29，为判断T265 Z轴能否避免激光照到小车圆盘时引起的高度阶跃，完成两次`1.00m -> 0.15m -> 自动降落`实飞对比。

- **关键发现**：两种高度全航程变化高度相关（相关系数约0.994），且稳定段标准差约1～2cm；但1m处T265相对激光分别偏高7.0cm、偏低4.7cm，跨次绝对偏差变化约11.7cm。
- **高度决策**：T265负责连续相对高度；起飞后在激光可靠观测地面时校准`laser_height - t265_z`偏置；视觉锁定小车上方后冻结偏置，不让圆盘激光距离覆盖巡航世界高度。
- **降落决策**：动态降落末段重新使用激光，将其解释为无人机到圆盘的相对距离，用于低速下降和近盘/触地判定。
- **影响范围**：`drone_control/basic/Mission_GPT.py`高度日志、D题无人机高度源选择、动态降落分阶段逻辑。
- **后续动作**：补做地面往返阶梯、60～120秒长时悬停和等高板激光阶跃测试；在此之前不拆除激光，不把T265作为未校准的唯一绝对高度源。

两次实飞T265置信度均为3，航线均以0.15m为最后导航高度，随后进入DESCEND/LAND并正常锁桨。
