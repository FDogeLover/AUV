# 立体货架盘点赛题坐标系

`drone_control/warehouse_inventory` 的飞行路径坐标约定：

- T265 局部原点设在起飞点；
- `+Y` 对应场地 5 m 长边方向；
- `-X` 对应场地 4 m 宽边方向；
- `+Z` 竖直向上。

图纸坐标与飞行坐标必须通过统一变换函数转换，不能在路线和货位代码中各自交换
X/Y或散落正负号。若图纸使用 `u` 表示5 m长边、`v` 表示4 m宽边，起飞点图纸
坐标为 `(u0, v0)`，则基础映射为：

`x_flight = -(v - v0)`，`y_flight = u - u0`，`z_flight = z`。

最终仍需用实物摆放方向和T265安装方向做手持/拆桨验证，不能只凭图纸确认符号。

- 扫描顺序是 A/C 先上层后下层，B/D 先下层后上层，以减少额外往返。
