# 2026-07-30 D题 AprilTag＋蓝框融合视觉伺服

## 目标

验证“25 cm蓝色方形外框＋中心ID 0 AprilTag”的融合定位，并形成简单、连续的无人机XY视觉追踪流程。

## 完成项

- Cyber Camera新增 `apriltag_blue_fusion`：正确Tag负责首次身份确认，蓝色外框负责高频中心定位，颜色失效时回退Tag直接识别和短时光流。
- VS1新增 `APRILTAG_VALID` bit 7、`TEMPORAL_TRACKED` bit 8、`COLOR_SHAPE_TRACKED` bit 9；蓝色和光流均不能独立建立身份。
- RDK接受颜色融合观测；静态专项现已将Tag直接、颜色和光流统一限速0.08 m/s，使用0.10 m/s²加速度、0.8 m/s³ jerk整形，并保持观测新鲜度和错误ID门禁。
- 最终实飞标定Y轴：画面上方对应无人机 `-Y`，使用 `error_y=cy-240`；X仍为`error_x=320-cx`。
- 删除运行时0.5 m软围栏对正常追踪的干预；专项测试暂保留0.8 m紧急半径。
- 实现持续追踪：1.5 m确认Tag后立即启用XY控制，下降到1.0 m期间持续接管，到达1.0 m后继续居中。
- 增加只观察实飞入口：1.5 m悬停采数时视觉不输出XY速度，最终仍使用0.15 m零停留末航点。

## 实飞结论

### 1.5 m只观察悬停

- 14.97秒内记录152帧，序号缺口0，观测频率10.09 Hz。
- 有效检测149帧（98.0%）：颜色120帧、光流24帧、Tag直接5帧、完全丢失3帧。
- 最长完全丢失约0.25秒；平均接收年龄17.3 ms。
- 颜色连续帧中心变化中位数2.24 px，融合检测具备进入低速闭环的稳定性。

### 融合闭环实飞1

- 1.5 m未居中即下降到1.0 m，目标偏移随高度降低放大并部分出画，造成长时间丢失。
- 重获后X方向正确，Y方向错误，目标被推向画面上边缘。
- 结论：修正Y符号，并避免下降期间关闭XY追踪。

### 融合闭环实飞2

- 固定1.5 m验证XY，将像素误差从约227 px降至最小31 px，下降约86%。
- XY方向和收敛正确；最大速度0.12 m/s，没有触发0.6 m旧硬围栏。
- 未满足严格居中保持条件的主要原因是旧0.5 m软围栏限制继续向目标移动。

### 持续下降实飞与过冲修正

- 状态机成功在1.5 m接管视觉、同步下降并到达1.0 m，说明持续追踪流程已跑通。
- 无人机向目标移动后飞过头，目标中心约由`(552,248)`移动到`(455,55)`并从画面上边缘丢失；旧世界目标位置/速度估计在静态目标上产生约0.94 m漂移，是持续输出同向速度的主要原因。
- 静态专项已移除`PlatformTracker`世界目标速度估计和视觉速度前馈，改为“3帧相对误差中值→按当前高度换算→直接P控制→速度/加速度/jerk整形”。目标进入约0.05 m死区后制动，视觉失效0.3秒后严格归零并交回T265保持。

### 相对误差P闭环首飞与Y轴最终标定

- 控制器最大输出0.08 m/s，T265记录相对接管点位移约0.46 m，证明视觉控制确实执行，并非始终悬停。
- 初始目标约`(452,139)`；负X命令使X一度到399、向中心靠近，正Y命令却使Y到54、继续靠近上边缘。因此X正确、Y反向。
- 当前只把Y改为`error_y=cy-240`；P控制、死区、限速、加速度、jerk和丢失保持逻辑不变。

### Y轴翻转后实飞与降振参数

- 目标从`(453,373)`收敛到最小`(320,239)`，确认X、Y符号均正确。
- 此后目标穿过中心并往复，X范围226～454、Y范围154～373；用户观察到的“X远离”发生在越过中心以后，不应翻转X。
- 为提前减速并缩短制动距离，静态专项调整为`Kp=0.35`、统一限速0.06 m/s、最大加速度0.15 m/s²、最大jerk 1.0 m/s³；轴向、死区和丢失保持逻辑不变。

### 降振实飞与T265速度阻尼

- 降振参数将最大半径从0.356 m降至0.322 m、后半段误差P90从102 px降至69.6 px、最终误差从34 px降至28 px，但仍未稳定保持中心。
- 飞控速度命令与T265实际速度的相关峰值滞后约1.2～1.4秒；同期航向约-3°～+3.6°，不是坐标旋转导致。
- 当前在视觉相对位置P项上加入`-Kd*v_t265`，`Kd=0.50`。该D项来自T265实际速度，不对视觉像素做差分，也不恢复视觉目标速度前馈。

### T265阻尼实飞与移动目标限速

- D阻尼将后半段平均误差从57.5 px降至39.9 px、P90从69.6 px降至56.1 px、50 px内占比从27.5%提高到73.3%，证明速度阻尼有效。
- 零命令周期的T265实际速度中位数仍为0.044 m/s，73.3%的周期超过0.03 m/s；代码现改为位置死区内继续D制动，只有位置误差不超过0.05 m且实际速度不超过0.02 m/s才判定居中。
- 为下一阶段低速移动目标测试，可靠完整视觉观测最高限速提高到0.15 m/s；`PARTIAL_COARSE`仍保持0.06 m/s，加速度和jerk限制不变。

### 固定小车速度前馈

- 移动目标实飞能够勉强跟随，但实际命令最高0.102 m/s、均值0.033 m/s，后半段平均误差52.4 px；提高限速没有解决缺少目标速度的问题。
- 临时测试配置加入固定平台速度`(X=0.00,Y=+0.10) m/s`，控制律为`v_platform + Kp*e + Kd*(v_platform-v_drone)`，总限速0.15 m/s。
- 固定前馈仅用于沿T265 `+Y`的匀速直线测试；视觉丢失仍交回T265原地保持，转弯/变速时必须改用实时小车速度，不得继续固定推送。
- 当前移动目标专项的发现高度和测试高度均设为1.5 m；确认Tag后全程保持1.5 m伴飞20秒，不下降到1.0 m，也不因居中保持3秒提前结束。

### T265地图点位测绘

- 地图到位后暂停固定`+Y 0.10 m/s`前馈，运行配置恢复`(0,0)`，避免误启动持续速度。
- 新增`t265_map_point_recorder.py`：不连接飞控、不解锁，H首点建立零点；每点采集3秒并记录中位坐标、标准差、yaw、速度、置信度和返回H闭环误差，同时保存CSV与原始JSONL。
- 首轮采用拆桨人工移动，建议`H→A→B→C_IN→C_OUT→D→H`连续三圈；通过后再实飞确认。
- 首轮H/A/B有效坐标分别为`(0,0)`、`(0.364,0.812)`、`(0.319,2.289)`m；C入口采样发生灾难性失跟，3秒轨迹跨度约13.84 m、虚假速度最高5.26 m/s，随后置信度降至0，C点已判无效。
- 记录工具现对标准差、静止速度、采样跨度和相邻点跳变执行硬拒绝；灾难性漂移自动结束整轮，不能继续使用已损坏坐标系。
