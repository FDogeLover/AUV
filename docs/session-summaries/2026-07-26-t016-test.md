## 💡 决策与备注

- **长路径超时问题**：`arrival_timeout_max=5.0s + 1.5s hold` 对 2m 距离不够用，WP1~WP4 均 timeout 跳点。实际短距/常规飞行不受影响，暂不调整参数，后续根据实际需要再改
- **分析脚本 Bug**：原 `flight_log_analyzer.py` 计算 XY 偏差时用的是 `sqrt(pos[0]^2+pos[1]^2)`（到原点距离），而非 `sqrt((pos[0]-target[0])^2+(pos[1]-target[1])^2)`（到目标点距离），导致 timeout 航点显示偏差巨大。已用 `analyze_t016.py` 修正
