## T-017 T265/激光高度对比补充

- `Mission_GPT.py`飞行日志已增加`laser_height_m`、`t265_raw_z_m`、`t265_filtered_z_m`和`t265_confidence`。
- 使用专用航线完成两次自动实飞：`(0,0,1.00m) -> (0,0,0.15m) -> DESCEND -> LAND`，两次均正常锁桨。
- 1m稳定段激光均值为1.010m/1.012m，T265均值为1.080m/0.965m，分别偏高7.0cm、偏低4.7cm。
- 两种高度全航程变化高度相关（相关系数约0.994），稳定段波动均约1～2cm，但T265每次初始化后的绝对偏差不固定。
- 决策：T265用于连续相对高度；起飞后用可靠激光数据校准偏置；锁定小车上方后冻结偏置；动态降落末段将激光解释为对圆盘相对距离并重新用于近盘/触地判定。
- 尚未完成等高板阶跃、地面往返阶梯和60～120秒长时悬停，因此不拆除激光，也不启用T265未校准单源绝对高度。
