# 分工计划02：无人机控制

## 目标

在现有T265、Pi/RDK、STM32和安全底座上完成任务一抛投与任务二动态起降，优先实现视觉伴飞闭环。

## 输入与输出

- 输入：VS1视觉观测、T265位姿/速度、STM32遥测、DCP小车状态与启动事件。
- 输出：STM32速度/高度/航向指令、DCP无人机状态/触地/完成事件。
- 协议：只引用 `../communication_protocol.md`。

## 固定机头与视觉坐标

- 无人机起飞后保持固定机头，不跟随小车航向旋转。
- 水平视觉伺服始终在固定的相机/机体坐标系内，根据目标中心相对画面中心的误差控制前后、左右速度。
- 单个AprilTag位于降落圆盘中心，因此小车转向不会引入Tag安装偏移；Tag航向仅用于诊断、转弯识别和可选速度前馈。
- 如果以后把Tag移出圆盘中心或增加多Tag，必须用Tag航向旋转已标定的安装偏移后再计算降落中心，不能使用固定图像偏移。

## 高度参考策略

当前候选架构为“T265世界高度主控、激光近地辅助”，目的是避免激光从地面切换到小车圆盘后触发无人机整体爬升。

- 起飞、H到B、B到C和C到D伴飞优先使用相对起飞点归零后的T265 Z轴作为世界高度。
- 视觉锁定圆盘时，激光距离不得未经分类直接覆盖世界高度或进入巡航定高闭环。
- 激光保留为平台相对距离、近地安全和最终下降辅助，不在完成T265 Z轴验证前拆除。
- 已有飞行日志中的`pos[2]`会被激光高度覆盖；既有0.5/1.0/1.5m高度测试不能证明T265 Z轴精度。
- T265初始化必须在地面、置信度稳定且起飞之前完成，并记录本次任务的Z轴零点。
- 动态降落前半程可按`T265高度 - 已标定圆盘离地高度`估计对盘高度；最终触地不能仅由T265高度阈值判定，仍需低速下降和飞控触地/锁定状态确认。

在切换主高度源前必须通过：

1. 地面0/0.3/0.6/1.0m往返阶梯测试：平均误差不超过5cm、静止标准差不超过2cm、回零误差不超过5cm、无超过10cm跳变。
2. 60～120秒实飞悬停对比：记录原始T265 Z、激光距离、置信度、垂直速度和控制输出。
3. 等高板进入激光光斑测试：激光允许出现接近平台高度的阶跃，T265 Z不得同步产生阶跃。
4. 上述测试失败时保持现有激光主高度，不启用T265单源高度控制。

## 启动流程

1. 程序上电自启动，先初始化Cyber Camera链路、飞控串口和蓝牙。
2. 等待用户完成T265拔插；检测设备后自动初始化、autoset并等待置信度。
3. 完成板载预检和起飞警示后发送 `UAV_READY`。
4. 只接受一次有效 `CAR_START`，立即起飞。

## 任务一

```text
垂直起飞 -> 150cm悬停3秒 -> T265飞向B附近
-> B前视觉截获 -> B-C稳定伴飞
-> C-D低速区投放 -> 退出视觉 -> 返回H -> 降落上锁
```

## 任务二

```text
起飞与伴飞 -> B-C对中/下降准备 -> C-D低速分级下降
-> 多尺度视觉 -> 最长0.5秒/100mm终端预测 -> 必要时越过D继续直到安全触地 -> 随车5秒
-> 保持车速短暂离台 -> 退出伴飞 -> 返回H -> 降落上锁
```

## 工作内容

- 相机坐标、机体坐标和T265世界坐标变换。
- 平台世界位置/速度估计。
- 速度前馈、相对位置/速度反馈和限幅。
- 投放门限、防重复释放。
- 动态下降、多尺度近地视觉、限时终端预测、多源触地确认、驻留、二次起飞和返航。
- 舵机投放由 `drop_controller` 门控、`payload_actuator` 执行动作并反馈；反馈不确定时不重复释放。
- `/dev/bt_serial` 115200双向接收、发送、ACK、重发和链路统计。
- T265/视觉/蓝牙/地面站失效的明确降级行为。

## 验证

- 板载最小检查后尽早实飞，不建设复杂动力学仿真。
- 静态平台采数与低速闭环。
- 多初始偏差静态收敛。
- 真实小车直线和整圈伴飞。
- 投放后再进入动态降落实飞阶梯。
- 动态下降先分别验证80/50/30cm复飞点，再验证近地特征切换和终端预测，最后才允许触地。

## 验收

- 同一时刻只有一个模块写飞控水平速度。
- 旧视觉帧、旧session和重复启动不能触发动作。
- 地面站/小车遥测异常不阻塞30ms飞行主循环。
- 完整日志包含协议seq、观测年龄、T265原始/滤波Z、激光距离、所选高度源、控制输出和状态转移。
- T265持续失效时不盲返H；终端预测超时或超过100mm仍未触地时必须停止盲降并重获目标。
- 贴近平台时二次起飞门禁允许新鲜 `CAR_STATE` 提供速度，不要求圆环仍完整可见；视觉和车速都失效时保持平台安全态。
