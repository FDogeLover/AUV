# 分工计划02：无人机控制

## 目标

在现有T265、Pi/RDK、STM32和安全底座上完成任务一抛投与任务二动态起降，优先实现视觉伴飞闭环。

## 输入与输出

- 输入：VS1视觉观测、T265位姿/速度、STM32遥测、DCP小车状态与启动事件。
- 输出：STM32速度/高度/航向指令、DCP无人机状态/触地/完成事件。
- 协议：只引用 `../communication_protocol.md`。

## 固定机头与视觉坐标

- 无人机起飞后保持固定机头，不跟随小车航向旋转。
- 水平视觉伺服始终在固定的相机/机体坐标系内，根据目标中心相对画面中心的误差控制前后、左右速度。
- 2026-07-30实飞最终确认当前外接CSI与飞行链路的方向：画面左方对应无人机 `+X`，画面上方对应无人机 `-Y`。640×480图像的控制误差定义为 `error_x=320-cx`、`error_y=cy-240`，因此目标在画面右上方时输出 `-X、-Y`。该结论来自闭环运动时序，不再采用静态照片方向推断。
- 单个AprilTag位于降落圆盘中心，因此小车转向不会引入Tag安装偏移；Tag航向仅用于诊断、转弯识别和可选速度前馈。
- 如果以后把Tag移出圆盘中心或增加多Tag，必须用Tag航向旋转已标定的安装偏移后再计算降落中心，不能使用固定图像偏移。

## 高度参考策略

已采纳“T265连续相对高度 + 激光分阶段绝对/对盘距离”的融合架构。目的是避免激光从地面切换到小车圆盘后触发无人机整体爬升，同时不把T265当成未经校准的唯一绝对高度源。

- 起飞后、激光仍可靠观测地面时，计算`laser_height - t265_z`偏置；只在数据有效且飞行稳定时慢速更新。
- H到B、B到C和C到D伴飞使用“T265 Z + 已校准偏置”作为连续巡航高度参考。
- 视觉锁定圆盘或确认进入小车上方后冻结偏置；激光距离不得再直接覆盖世界高度或进入巡航定高闭环。
- 动态降落末段重新使用激光，此时其语义为“无人机到圆盘的相对距离”，用于低速下降、近盘判定和触地去抖。
- 激光保留为起飞后偏置校准、平台相对距离、近地安全和最终下降辅助，不拆除。
- 已有飞行日志中的`pos[2]`会被激光高度覆盖；既有0.5/1.0/1.5m高度测试不能证明T265 Z轴精度。
- T265初始化必须在地面、置信度稳定且起飞之前完成，并记录本次任务的Z轴零点。
- 动态降落前半程可按`T265高度 - 已标定圆盘离地高度`估计对盘高度；最终触地不能仅由T265高度阈值判定，仍需低速下降和飞控触地/锁定状态确认。

2026-07-29 T-017两次自动实飞结果：1m稳定段T265相对激光分别偏高7.0cm、偏低4.7cm，跨次绝对偏差变化约11.7cm；两者全航程变化相关系数约0.994，且稳定段标准差约1–2cm。因此T265适合连续相对高度，但现阶段不能单独提供未校准的绝对高度。

2026-07-29 T-018实飞采用 `1.5m → 0.15m → DESCEND`：最终0.15m航点使用独立的0秒停留和20秒下降超时，到达确认后没有再等待15秒，随后正常进入DESCEND/LAND并锁桨。1.5m观察航点最终以总超时推进；虽然1.4m以上已有约16.3秒数据，但说明“到达后观察计时”仍会被从航段开始计算的总超时打断，后续应让已确认到达后的观察阶段不再受原航段超时抢占。

## 视觉伺服稳定与预测策略

视觉测量不能逐帧直接映射为飞行速度，否则像素噪声、轮廓切换和短暂漏检会变成速度正负跳变，引起无人机抖动。首轮蓝色方块闭环采用以下分层处理：

1. **有效性门控**：检查VS1 CRC、stream/seq连续性、观测年龄、`quality`和flags。`PARTIAL`只进入低速粗跟踪，完整目标连续3帧后才进入精定位。
2. **测量去噪**：静态专项使用3帧中心误差中值抑制离群点，再按当前高度和相机焦距换算为相对水平误差；不估计静态目标的世界位置或速度。
3. **丢失处理**：当前专项测试的新鲜度门限为0.3秒。超过门限立即清除相对误差、将视觉输出严格归零并交回T265保持当前点，不按旧速度盲追。
4. **控制死区**：中心附近设置约10～15px死区，死区内水平目标速度为0；死区外使用连续软启动，避免跨阈值时速度突跳。
5. **速度与加速度限制**：移动目标专项的可靠完整中心观测最高水平限速0.15m/s，低质量粗跟踪仍限速0.06m/s；加速度限制0.15m/s²、jerk限制1.0m/s³。控制输出经过整形，不允许单帧检测变化直接改变大速度。
6. **控制形式**：使用“3帧中值视觉相对误差P控制 + T265实际速度D阻尼 + 约0.05m死区 + 统一限速 + 加速度/jerk整形”。关闭视觉速度前馈，不使用容易放大噪声的像素D项。移动小车阶段的速度前馈由双T265提供，不再从像素变化猜测目标速度。
7. **状态滞回**：粗跟踪、精定位、居中完成和目标丢失使用不同进入/退出阈值，防止在边界反复切换。

静态目标专项不再做运动预测；其目标是先验证相对位置反馈能够稳定居中。以后动态伴飞由小车T265提供速度前馈，视觉只修正相对位置误差，避免视觉短时波动被解释成小车真实速度。

### 当前持续追踪状态机（2026-07-30）

专项静态实飞已确认“目标只要可靠出现在画面中，就持续追踪其中心”是主逻辑，不再把下降前预居中和1.0 m重新接管拆成两个视觉阶段：

```text
1.5 m确认指定Tag身份
  → 立即启用XY视觉伺服
  → XY持续追踪，同时基础导航只控制高度下降到1.0 m
  → 1.0 m稳定后继续追踪，满足居中保持时间才结束专项测试
```

- 下降期间即使暂时居中也不提前关闭视觉；到达1.0 m并稳定后才允许“居中完成”。
- 视觉控制XY时，基础高度航点的XY随飞机当前位置更新，避免基础T265位置闭环把飞机拉回最初接管点。
- 新鲜视觉有效时持续修正；完全失效超过0.3秒后停止视觉速度并用T265保持当前点，重新识别后自动继续追踪。
- 固定接管点0.5 m软围栏已从运行配置关闭。专项测试暂用0.8 m紧急半径防止失控；最终伴飞必须改为场地/赛道边界和任务走廊，不能以初始接管点限制跟车距离。
- 专项测试保留20秒总时限；移动目标可靠完整观测最高限速0.15 m/s，位置`Kp=0.35`、T265速度`Kd=0.50`，最大加速度0.15 m/s²、最大jerk 1.0 m/s³。位置进入0.05 m死区后P项归零，但D阻尼持续到实际水平速度不超过0.02 m/s；低质量粗跟踪仍限速0.06 m/s。

2026-07-29第二次融合闭环实飞已将中心误差从约227 px降至最小31 px，XY方向正确。随后持续追踪下降实飞完成了1.5 m接管和下降到1.0 m，但旧世界目标速度估计造成过冲并将目标推出画面。当前已改为静态相对误差P闭环，下一项验证是目标接近中心时能及时减速、不再飞过头。

2026-07-30相对误差P闭环首飞进一步确认Y轴仍为反向：目标中心由约`(452,139)`向上移动到`(399,54)`，而同期命令为负X、正Y；X向中心收敛、Y向边缘发散。T265记录相对接管点位移约0.46 m，说明不是控制未执行。当前仅翻转Y为`error_y=cy-240`，其余P控制和安全限制保持不变。

Y轴翻转后的实飞从`(453,373)`收敛到最小`(320,239)`，证明X、Y方向均正确；随后X范围达到226～454、Y范围达到154～373，属于穿越中心后的低阻尼往复，不是X反向。参数因此从`Kp=0.75、vmax=0.08、amax=0.10、jerk=0.8`调整为`Kp=0.35、vmax=0.06、amax=0.15、jerk=1.0`。

降振参数实飞将最大半径从0.356 m降至0.322 m、后半段误差P90从102 px降至69.6 px，但仍存在往复。对齐`flight_data.jsonl`中的速度命令与T265实际速度后，水平响应相关峰值约滞后1.2～1.4秒，航向仅在约-3°～+3.6°变化，排除坐标旋转。当前加入`-Kd*v_t265`速度阻尼，`Kd=0.50`；它不使用视觉差分或视觉目标速度。

T265速度阻尼实飞把后半段平均误差从57.5 px降到39.9 px、P90从69.6 px降到56.1 px、50 px内占比从27.5%提高到73.3%。日志同时发现零命令周期的T265实际速度中位数仍为0.044 m/s，73.3%的零命令周期速度超过0.03 m/s；因此位置死区内改为继续D制动，直到速度进入0.02 m/s死区。为进行低速移动目标跟踪，可靠完整观测限速提高到0.15 m/s。

低速移动目标实飞证明静态控制器能够勉强追踪，但总限速提高到0.15 m/s后实际命令最高仅0.102 m/s、均值0.033 m/s，后半段平均误差52.4 px；瓶颈是缺少目标速度而不是限速。当前临时测试配置加入固定平台速度`(0.00,+0.10) m/s`，控制律为`v_platform + Kp*e + Kd*(v_platform-v_drone)`，总输出仍限0.15 m/s。该固定前馈只适用于小车沿T265 `+Y`匀速直线测试，转弯或变速前必须关闭或由实时小车速度替换。

固定前馈移动专项将发现高度和测试高度统一为1.5 m：起飞到1.5 m确认Tag后保持该高度伴飞20秒，不再下降到1.0 m，也不因居中保持3秒提前结束。1.5 m已有约98%有效检测率实测，且更大视野更适合当前0.10 m/s直线移动测试；1.0 m及以下留给后续投放和动态降落阶段。

地图到位后暂停固定`+Y 0.10 m/s`前馈，运行配置恢复平台速度零值。新增`t265_map_point_recorder.py`用于拆桨人工测绘：H首点建立相对零点，每个点自动采集3秒并输出中位坐标、XY标准差、yaw、速度和置信度，重复H点时计算闭环误差；CSV与原始JSONL同时保存。建议顺序为`H→A→B→C_IN→C_OUT→D→H`，连续三圈后再重新初始化复测。

首次人工测绘得到H=`(0,0)`、A=`(0.364,0.812)`m、B=`(0.319,2.289)`m；进入C点采样时T265在3秒内从约`(5.49,34.12)`虚假漂到`(6.11,47.95)`m，速度最高5.26 m/s，随后置信度降至0，C数据无效。工具已改为对XY标准差、静止速度P90、3秒轨迹跨度和相邻点距离做硬拒绝；速度>1 m/s、跨度>0.5 m或置信度归零时自动结束整轮，要求返回H拔插重测。置信度2本身不能证明坐标有效。

后续发现T265在完全静止冷启动时可能5秒无Pose帧，而旧`t265_class`把`last_confidence`默认设为3，造成“伪就绪”。动态轻微移动初始化后，Pose恢复约190～192Hz并能静止持续输出。现已把初始置信度改为0，记录最后Pose帧时间和计数；地图工具要求Pose年龄≤0.20秒，旧帧即使置信度显示正常也必须拒绝。每次拔插/重启后应先让T265在有纹理视野中缓慢平移和小角度转动，等待真实Pose就绪。

在切换主高度源前必须通过：

1. 地面0/0.3/0.6/1.0m往返阶梯测试：平均误差不超过5cm、静止标准差不超过2cm、回零误差不超过5cm、无超过10cm跳变。
2. 60～120秒实飞悬停对比：记录原始T265 Z、激光距离、置信度、垂直速度和控制输出。
3. 等高板进入激光光斑测试：激光允许出现接近平台高度的阶跃，T265 Z不得同步产生阶跃。
4. 上述测试失败时保持现有激光主高度，不启用T265单源高度控制。

## 启动流程

1. 程序上电自启动，先初始化Cyber Camera链路、飞控串口和蓝牙。
2. 等待用户完成T265拔插；检测设备后自动初始化、autoset并等待置信度。
3. 完成板载预检和起飞警示后发送 `UAV_READY`。
4. 只接受一次有效 `CAR_START`，立即起飞。

## 任务一

```text
垂直起飞 -> 150cm悬停3秒 -> T265飞向B附近
-> B前视觉截获 -> B-C稳定伴飞
-> C-D低速区投放 -> 退出视觉 -> 返回H -> 降落上锁
```

## 任务二

```text
起飞与伴飞 -> B-C对中/下降准备 -> C-D低速分级下降
-> 多尺度视觉 -> 最长0.5秒/100mm终端预测 -> 必要时越过D继续直到安全触地 -> 随车5秒
-> 保持车速短暂离台 -> 退出伴飞 -> 返回H -> 降落上锁
```

## 工作内容

- 相机坐标、机体坐标和T265世界坐标变换。
- 平台世界位置/速度估计。
- 速度前馈、相对位置/速度反馈和限幅。
- 小车`CAR_STATE`以10 Hz发送13字节载荷；无人机只采用会话匹配、seq更新、
  `state_flags.bit4`有效且接收年龄不超过300 ms的数据。
- 小车与无人机后续统一世界速度坐标系；当前接收端原样保存`vx/vy`，不做临时轴旋转。
- 当前`CAR_STATE`速度只用于通信记录和诊断，不接入任务一状态机，不参与速度前馈，
  也不直接接管飞控；待坐标统一及控制方案单独确认后再启用。
- 投放门限、防重复释放。
- 动态下降、多尺度近地视觉、限时终端预测、多源触地确认、驻留、二次起飞和返航。
- 舵机投放由 `drop_controller` 门控、`payload_actuator` 执行动作并反馈；反馈不确定时不重复释放。
- `/dev/bt_serial` 115200双向接收、发送、ACK、重发和链路统计。
- T265/视觉/蓝牙/地面站失效的明确降级行为。

## 验证

- 板载最小检查后尽早实飞，不建设复杂动力学仿真。
- 静态平台采数与低速闭环。
- 多初始偏差静态收敛。
- 真实小车直线和整圈伴飞。
- 投放后再进入动态降落实飞阶梯。
- 动态下降先分别验证80/50/30cm复飞点，再验证近地特征切换和终端预测，最后才允许触地。

## 验收

- 同一时刻只有一个模块写飞控水平速度。
- 旧视觉帧、旧session和重复启动不能触发动作。
- 地面站/小车遥测异常不阻塞30ms飞行主循环。
- 完整日志包含协议seq、观测年龄、T265原始/滤波Z、激光距离、所选高度源、控制输出和状态转移。
- T265持续失效时不盲返H；终端预测超时或超过100mm仍未触地时必须停止盲降并重获目标。
- 贴近平台时二次起飞门禁允许新鲜 `CAR_STATE` 提供速度，不要求圆环仍完整可见；视觉和车速都失效时保持平台安全态。
