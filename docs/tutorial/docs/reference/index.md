!!! tip "如何使用这些资料"
    1. **通信协议**是本项目串口协议的基础，建议优先阅读
    2. **原理图**用于硬件排线和接口确认
    3. **Datasheet**在需要深入理解某个传感器或 MCU 外设时查阅
    4. **历年赛题**帮助理解电赛题目演变和考察重点
    5. **固件源码**在需要修改飞控行为时参考（注意 GB2312 编码）
