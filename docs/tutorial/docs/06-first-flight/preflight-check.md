# 飞行前检查

!!! danger "真机飞行前确认"
    确保你已经在桌面 DRY_RUN 模式下跑通过至少一次完整流程。确保飞行区域3米内无人员、宠物、贵重物品。确保遥控器已对频且可随时手动接管。

## 六项检查清单（每次必做）

- [ ] **电池检查** — 电池满电？电量显示器正常？接口插紧？（续航：新电池~5分钟，旧电池~4分钟）
- [ ] **硬件连接** — T265插紧USB3.0？串口线连接可靠？激光/光流模块接线正常？螺旋桨安装方向正确且紧固？
- [ ] **遥控检查** — 遥控器已开机？油门在最低位？模式开关可切换到手动模式？
- [ ] **航线规划** — `router.txt` 航点坐标合理？首次飞行建议用默认短路径（0.6m前飞，1m高度）
- [ ] **日志清理** — 移走或备份旧的 `flight_data.jsonl`
- [ ] **安全区域** — 周围3米内清空人员？操作人员站在安全位置（建议无人机后方2米外）？

## 默认航线示例

```
0.0,0.0,1.0    # 悬停起飞点正上方，高度1m
-0.6,0.0,1.0   # 向前飞0.6m
-0.6,0.0,0.2   # 原地下降至0.2m，准备降落
```

坐标单位：米，以起飞点为原点，T265局部坐标系。
