# 起飞流程

## 六步起飞

### Step 1：上电

先开遥控器，再接电池。等待飞控初始化完成（飞控LED状态正常）。

!!! tip "顺序不能反"
    先开遥控再接电池，确保遥控器能第一时间接收飞控信号。如果先接电池再开遥控，飞控可能在遥控未就绪时进入异常状态。

### Step 2：SSH 登录板子，启动程序

```bash
ssh ubuntu-pi
cd ~/<你的工作目录>/drone_control/basic
python3 main.py
```

### Step 3：等待初始化完成

观察LED状态：

| LED状态 | 含义 |
|--------|------|
| 黄灯/闪烁 | 初始化中（T265启动、串口连接） |
| 绿灯常亮 | 就绪，等待按键起飞 |

!!! warning "T265检测失败"
    如果T265检测不到（红灯/报错），可**物理拔插**T265 USB口，程序会自动重连。

### Step 4：所有人员撤离，按下一键起飞按钮

按下 BCM5 物理按键后：

| 阶段 | LED | 动作 |
|------|-----|------|
| 警示期 | 红灯常亮5秒 | **立即远离无人机** |
| 解锁 | — | 飞控自动解锁，电机怠速 |
| 离地 | — | 盲飞离地至35cm |
| 定位 | — | 激活T265定位，PID爬高 |

### Step 5：飞行中监控

手不离遥控器，密切关注无人机姿态。

- 正常：无人机按 `router.txt` 航线逐航点飞行，每个航点到达后悬停1.5秒
- 异常（偏航/飘移/高度异常）：**立即切手动模式接管**

### Step 6：自动降落

最后一个航点到达后，状态机进入 DESCEND → LAND。无人机缓降至地面。

!!! danger "目视确认电机停转"
    此时手勿离开遥控器，**目视确认螺旋桨完全停转**（参考 [铁律一](../02-safety/critical-rules.md)，land() 可能假阳性）。
