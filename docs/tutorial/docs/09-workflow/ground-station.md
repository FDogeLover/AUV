# 匿名上位机使用指南

凌霄IMU 官方地面站工具（"匿名科创"品牌，V7.3-20240423）。

!!! info "软件位置"
    `D:\Competition\自组无人坤\1\匿名上位机.exe`

    这是一个独立的外部调试工具，与 `drone_control` 仓库代码没有代码层面的关联。

## 这个软件是干什么的

它是凌霄IMU的调参/调试工具，可以实时查看无人机状态、调整飞控参数、校准传感器、升级固件。与 Pi ↔ 飞控 的串口链路（`Lprotocol.py`）不同——这个软件直接对话凌霄IMU，走的是匿名通信协议V7的另一套连接。

**两种连接方式：**

| 连接方式 | 接口 | 适用场景 |
|---------|------|---------|
| **USB HID 有线** | USB 线直连凌霄IMU调试口 | 台架调试（拆桨通电测试、调PID、校准传感器） |
| **数传无线** | 数传模块连接飞控串口 | **飞行中实时监控**（可挂在地面看实时数据） |

!!! tip "飞行中也可以用"
    接上数传后，飞行过程中可以实时查看无人机状态数据，包括飞行模式、姿态、高度、速度等。适合飞行后复盘分析和飞行中实时诊断。

## 连接步骤

### 方式一：USB HID 有线连接（台架调试）

1. 打开 `匿名上位机.exe`
2. 右下角点 **连接设置**
3. `USBHID设置` 区域：点 **搜索**，等设备列表出现 **匿名控制台**，勾选它
4. 回到主界面，右侧点 **打开连接**
5. 连接成功后 `连接状态` 图标会变亮，`软件版本`/`硬件版本` 会显示实际值（未连接时全是 `NA`）

!!! warning "接口区分"
    USB 线必须接凌霄IMU的**调试口**，不是飞控连接 Pi 的那个串口口。两者物理接口不同，接错了搜不到设备。

### 方式二：数传无线连接（飞行中监控）

1. 将数传模块一端连接飞控的数传口，另一端通过 USB 接电脑
2. 打开 `匿名上位机.exe`
3. 右下角点 **连接设置**
4. `串口设置` 区域：选择对应的 COM 口，设置波特率（与飞控数传配置一致）
5. 回到主界面，右侧点 **打开连接**
6. 连接成功后即可实时查看飞行数据

!!! note "数传 vs USB HID"
    - **USB HID**：延迟极低、数据完整，适合台架精细调试
    - 数传：有无线传输延迟，但可以在飞行中实时监控，适合飞行测试和排障
    - 两种方式看到的数据内容相同，区别只在传输介质

## 六个功能页签速览

| 页签 | 干什么用 | 什么时候看 |
|---|---|---|
| **飞控状态** | 实时显示：飞行模式、锁定状态、roll/pit/yaw、高度、GPS、电压、水平/垂直速度 | 想快速看当前整体状态时 |
| **数据显示** | 完整协议帧浏览器，左侧树形列表按 Frame ID（0x01~0x51）组织，点开每个帧能看到具体字段和实时数值 | 想深挖某个具体数据（比如飞行模式的精确枚举值）时 |
| **飞控参数** | 166项参数的完整表格，含参数名、当前值、范围、说明 | 想查/改某个具体PID增益、限速、起飞高度等配置时 |
| **功能触发** | 磁力计校准、陀螺仪校准、快速水平校准、6面校准、清空APP（进固件升级模式） | 装机后首次校准，或怀疑传感器零点漂移时 |
| **凌霄IMU** | 控制参数微调滑块（对应飞控参数ID65）+ 校准按钮快捷方式 + 遥测帧发送频率配置 | 想调整单参数控制模式的响应/带宽，或开关某个遥测帧的输出时 |
| **地图显示** | GPS地图，没有GPS信号时是空白的 | 有GPS模块时看轨迹 |

## 对本项目排查有用的具体位置

### 看飞行模式（验证一键起飞后有没有真正切换模式）

**数据显示** 页签 → 展开 **Frame ID: 0x06（飞控运行模式）** → `FC_STA_FlyMode` 字段：

| 值 | 含义 |
|---|---|
| 0 | 姿态自稳 |
| 1 | 自稳+定高 |
| 2 | 定点飞行 |
| 3 | 程控飞行 |

同一展开区域还有：
- `FC_STA_SFlag`：0=锁定，1=解锁
- `FC_STA_CID`/`FC_STA_CMD0`/`FC_STA_CMD1`：当前执行的功能及参数，对应0xE0帧

**用法**：台架测试（拆桨、USB直连）时一边触发一键起飞，一边盯着 `FC_STA_FlyMode`，看它是不是从某个模式切到另一个模式、切换时机跟飞控发 `vel_z` 是否有重叠。飞行中用数传连接也可以实时观察模式切换。

### 看外接传感器连接状态（T265/光流是否被IMU正常识别）

**数据显示** 页签 → 展开 **Frame ID: 0x0E（外接模块工作状态）**：
- `FC_STA_I_GVEL`：通用速度传感器连接状态（T265速度就是走这个通道，`ext_sens.gen_vel`/CMD 0x33）
- `FC_STA_I_AALT`：附加测高传感器连接状态（激光高度）
- `FC_STA_I_GPOS`/`FC_STA_I_GPS`：通用位置传感器/GPS连接状态

如果这些值在飞行过程中掉线（变成0或异常值），说明IMU那边认为对应的外部数据源已经失效，会直接影响定点悬停/高度锁定的可靠性。

### 起飞相关参数

**飞控参数** 页签，序号 82-83：
- `TAKEOFFHIGH`：起飞后自动尝试定高到的目标高度（cm）
- `TAKEOFFSPEED`：起飞爬升速度（cm/s）

这两个参数决定了 `OneKey_Takeoff()` 触发的自主爬升行为，跟飞控自己算的 `height_set()` 输出是两套独立的东西。

## 常见注意事项

- 未连接时表格里全是 `NA`，不代表参数不存在，只是没读到实时值
- "飞控状态"页在断线后会保留最后一次连接时的数值（不会自动清空成NA），容易误以为是实时数据，注意看右下角"连接状态"图标确认真的在线
- 这个软件跟 `drone_control` 仓库没有任何代码层面的关联，纯粹是外部调试工具，不要把它的参数表当成本项目 Python/C 代码的配置来源
- 数传连接时注意波特率必须与飞控端数传配置一致，否则无法正常通信
