# 硬件清单

## 基础飞行最小配置

| 硬件 | 型号/规格 | 作用 | 接口 |
|------|----------|------|------|
| 飞控板 | STM32F407 + 凌霄IMU（集成模块） | 姿态自稳、电机控制 | — |
| 上位机 | 地瓜派 RDK X5 | 运行Python控制程序 | Linux |
| 视觉里程计 | Intel RealSense T265 | 提供局部坐标系位姿 | USB 3.0 |
| 高度传感器 | 光流模块内置激光 | Z轴定高（飞控融合后下发） | 飞控内置 |
| 一键起飞按钮 | 物理按键 | 触发起飞 | GPIO BCM5 / Pin29 |
| RGB警示灯 | 三色LED | 状态指示 | GPIO |
| 电池 | 3S 3300mAh / 3S 4000mAh / 4S 5300mAh | 供电 | XT60 |

!!! tip "电池续航"
    3S 电池约 4-5 分钟，4S 5300mAh 约 6-7 分钟。该数据基于**同高度航向飞行**测得，爬升/下降频繁时耗电会明显增大。规划航线时留足余量，首次飞行建议 1 分钟内完成。

## 可选硬件（进阶）

| 硬件 | 用途 | 需要的版本 |
|------|------|-----------|
| 核桃派 Cyber Camera | 目标检测，视觉伺服降落 | `competition_2026_d/vision/` |
| 蓝牙模块 | 空地通信（D题） | `competition_2026_d/` |
| 舵机 | 投放装置 | `competition_2026_d/` |
| OLED屏 | 状态显示 | `competition_2026_d/` |

!!! info "为什么选 CyberCamera？"
    视觉处理板有多种选择（K230、直接 USB 摄像头等）。本项目选 CyberCamera（核桃派）的核心原因：搭载 CentOS Linux，支持 SSH 直连，可以像普通 Linux 服务器一样远程改代码、调试算法，不需要拔板子接显示器。竞赛迭代速度优先。

## SSH 连接

| 主机别名 | IP | 状态 |
|---------|-----|------|
| `ubuntu-pi` | 动态IP（以 `~/.ssh/config` 为准） | 在线 |
| `orangepi` | 192.168.137.126 | 离线 |

```bash
# 连接板子
ssh ubuntu-pi
```
