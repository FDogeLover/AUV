## 四个 IMU 内部融合参数详解

这些参数作用于 IMU 模组**内部**的 EKF，通过上位机（匿名地面站）配置，飞控源代码里不涉及。含义如下：

### 1. 姿态融合参数 (0-100)

| 项目 | 说明 |
|------|------|
| **作用对象** | 加速度计修正陀螺仪姿态漂移的增益 |
| **原理** | 陀螺仪积分会随时间漂移，加速度计测得的重力方向可修正俯仰/横滚 |
| **值越大** | 加速度计权重高 → 漂移抑制快，但运动加速度干扰大 |
| **值越小** | 陀螺仪权重高 → 短时平滑，但长时间积分漂移累积 |
| **实践建议** | 多旋翼悬停 20-40，高速飞行适当降低 |

### 2. 罗盘融合参数 (0-100)

| 项目 | 说明 |
|------|------|
| **作用对象** | 磁力计修正偏航角（Yaw）的增益 |
| **原理** | 偏航误差无法用重力修正，只能靠磁力计或外部航向参考 |
| **值越大** | 偏航修正快，但易受电磁干扰抖动 |
| **值越小** | 偏航平滑，但磁干扰时校正慢 |
| **现场经验** | 遇到干扰时置 0 可以完全禁用罗盘修正，消除干扰导致的偏航旋转 |

### 3. 惯导水平面融合参数 (0-100)

| 项目 | 说明 |
|------|------|
| **作用对象** | 水平位置/速度观测（GPS/光流等）的校正增益 |
| **在纯IMU模式** | 如果没有外部水平观测源，此参数不产生实际效果 |

### 4. 惯导垂直融合参数 (0-100)

| 项目 | 说明 |
|------|------|
| **作用对象** | 气压计对 IMU 垂直通道的校正增益 |
| **原理** | IMU 垂直通道天然不稳定（加速度二次积分发散），必须靠气压计约束 |
| **值越大** | 气压计权重高 → 高度跟踪快，但噪声大 |
| **值越小** | 高度变化平滑，但长期漂移 |
| **注意** | 此参数控制的是 IMU 内部**气压计 vs 加速度计**的融合，**与激光测高无关** |

## 关键结论（来自源代码验证）

1. **飞控侧不做高度二次融合**：`User_Alt_Ctrl(ano_of.of_alt_cm, ...)` 直接使用光流模块的激光高度作为高度反馈，不跟 IMU 的高度估计做加权或切换
2. **IMU 不输出高度值**：IMU 内部融合了气压计+加速度计，但只输出 `vel_z`（垂向速度，`0x07` 帧），不输出绝对高度
3. **罗盘参数只影响 IMU 内部偏航估计**：飞控控制偏航用的是 T265 的 `t265.ya_f`，不是 IMU 的姿态角——但 IMU 内部罗盘融合异常会影响 `rt_tar` 控制帧的执行效果，进而间接导致偏航旋转
4. **四个参数都是 IMU 内部 EKF 的传感器信任权重**，不是飞控 PID 参数，也不是外环控制参数
