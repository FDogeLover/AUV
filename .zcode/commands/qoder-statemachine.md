---

用以下步骤完成状态机审查：

1. 确定目标文件：
   - 如果 $ARGUMENTS 非空，读取该路径
   - 如果为空，默认读取 `drone_control/warehouse_inventory/Mission_GPT.py`
2. 用 Read 工具读取完整文件内容
3. 用 Bash 调用 Qoder CLI：
   ```
   "C:\Users\FJJ\.qoder-cn\bin\qoderclicn\qoderclicn.exe" -p "<prompt>"
   ```
   prompt 内容：
   ```
   你是无人机任务状态机审查专家。以下是一个真实飞行无人机的任务状态机 Python 文件。

   请完成以下检查（每条给出相关代码行号）：

   1. 死锁状态：列出所有进入后没有无条件离开路径的状态（只能靠超时或外部信号离开标注"弱活性"；完全无法离开标注"死锁"）
   2. 降落保障：所有异常路径最终是否都能到达降落或紧急降落逻辑？列出不能到达降落的异常出口
   3. 超时覆盖：所有"等待类"状态（等待传感器/等待确认/等待稳定）是否都有超时退出？列出缺失超时的状态
   4. 状态计数：统计总状态数，列出所有状态名称

   文件内容：
   <文件内容>
   ```
4. 将 Qoder 的输出完整展示
5. 根据 Qoder 输出，如果发现了死锁或无降落保障的问题，提示用户："这些是安全关键问题，建议真机测试前修复"
