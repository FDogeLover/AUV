安全确认不能只问"现场有没有人能接管/区域是否开阔"这种笼统问题——如果这次测试专门在飞行区域里摆了一个物理测试物体（比如给雷达探测用的杆子），必须额外核对**既定航线(router.txt里的目标坐标)会不会正好经过这个物体的位置**。

**Why:** 2026-07-07 测试"飞行中雷达检测杆子"时，杆子摆在-X方向1m处，但当时的 `router.txt` 目标是飞到 `X=-1.8m`——航线会直接穿过杆子所在位置，而我确认安全条件时只问了笼统的"现场有人能接管吗"，没有具体核对航线和杆子位置是否冲突。这次侥幸没有造成实际碰撞（用户后来说明飞控没开电，飞机根本没真正起飞），但如果那次是真实飞行，会直接撞机。

**How to apply:** 以后只要用户提到"要同时测试雷达/视觉/其他传感器，需要在飞行区域摆放物理测试物体"这类场景，安全确认清单里必须加一条"航线是否会经过该物体位置"，需要的话主动提议缩短航线目标距离、留出安全余量（比如这次把 `-1.8m` 改成 `-0.6m`，给1m处的杆子留0.4m余量），不能等用户自己发现并提出来。
