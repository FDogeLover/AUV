# 地面站通信协议说明 v2.0

## 一、物理层

| 参数 | 值 |
|------|-----|
| 接口 | UART 串口 |
| 波特率 | 115200 bps |
| 数据位 | 8 |
| 校验位 | 无 |
| 停止位 | 1 |
| 流控 | 无 |
| Pi端设备 | `/dev/ttyS7` |
| 发送频率 | **100Hz**（每10ms一帧） |
| 帧格式 | 二进制定长 **5 字节** |

---

## 二、帧格式

```
字节0     字节1          字节2       字节3       字节4
 AA     waypoint_idx   animal_cls   animal_cnt    FF
0xAA      0~255          0~255       0~255      0xFF
```

| 字节 | 名称 | 类型 | 说明 |
|------|------|------|------|
| 0 | 帧头 | u8 | 固定 `0xAA`，用于帧同步 |
| 1 | `waypoint_idx` | u8 | 当前航点序号，范围 0~255 |
| 2 | `animal_cls` | u8 | 动物类别（见下表） |
| 3 | `animal_cnt` | u8 | 动物数量，`0`=飞行中/无新结果，`≥1`=有新结果 |
| 4 | 帧尾 | u8 | 固定 `0xFF`，用于帧校验 |

---

## 三、动物类别编码

| 值 | 含义 |
|----|------|
| 0 | tiger 虎 |
| 1 | wolf 狼 |
| 2 | monkey 猴 |
| 3 | peacock 孔雀 |
| 4 | elephant 象 |
| 0xFF | 无动物 |

**注意**：`cls` 只在 `cnt ≥ 1` 时有效。`cnt = 0` 时忽略 `cls` 字段。

## 四、发送时序与状态解读

### 核心机制：静默帧 + 检测点亮

```
初始状态:  [0, 0, 0, 0, 0]     ← AA=0，地面站忽略所有字节
飞行中:    [0, idx, 0, 0, 0]    ← navigate()每30Hz只更新idx
检测完成:  [AA, idx, cls, cnt, FF] ← _detect_accept()一次性点亮
           → 之后 send_dmz(100Hz) 持续广播，地面站随时可收到
```

**关键**：`AA/FF/cls/cnt` 仅由 `_detect_accept` 写入，`navigate()` **永不再抹零**。检测帧一旦点亮，就持续广播直到下一个格子检测覆盖。

### 4.1 初始静默

```
帧: 00 00 00 00 00    ← 起飞前，所有帧无效
```

地面站：忽略 `AA != 0xAA` 的帧。

### 4.2 飞行中（无检测结果）

```
帧: 00 01 00 00 00    ← 正在飞往第1个航点
    00 02 00 00 00    ← 正在飞往第2个航点
    ...
```

地面站：检查 `AA != 0xAA`，忽略。进度条的更新通过 `re_dmz` 监听或其他方式。

### 4.3 检测完成 — 地面站唯一关心的事件

每个航点检测完成后，**AA/FF/cls/cnt 点亮后永久保持**，直到下一个检测覆盖：

```
时间 →
                                      ↓ _detect_accept (7号点)
帧:  00 05 00 00 00  AA 07 03 02 FF  AA 08 03 02 FF  AA 09 03 02 FF  ...
                  ↑ 点亮！
                       ↑ idx自动跟随navigate递增

地面站读到: AA 07 03 02 FF:
  记录 last_handled = 7, 显示"7号点: peacock x2"

地面站读到: AA 08 03 02 FF:
  idx=8, 但 last_handled=7 → 更新 last_handled=8（清除旧缓存）
  如果cls/cnt和7号点的一样 → 跳过（这条是旧结果的重复广播）

地面站读到: AA 09 03 02 FF:
  idx=9, last_handled=8 → 同上，跳过。
  ...
  直到9号点检测完成: AA 09 FF 01 FF → 处理。
```

**地面站去重逻辑**：

```python
last_idx = -1     # 上次处理的航点号

if buf[0] == 0xAA and buf[4] == 0xFF:
    idx = buf[1]
    if idx != last_idx:     # ← 只处理新航点
        cls, cnt = buf[2], buf[3]
        # ... 显示结果 ...
        last_idx = idx
```

## 五、地面站接收伪代码

```python
import serial

ANIMALS = ["虎", "狼", "猴", "孔雀", "象"]
ser = serial.Serial("/dev/ttyS7", 115200, timeout=0.05)

buf = bytearray()
last_idx = -1     # 已处理的航点号，去重用

while True:
    buf.extend(ser.read(1))
    while len(buf) >= 5:
        # 只接收有效帧 (AA开头 + FF结尾)
        if buf[0] != 0xAA or buf[4] != 0xFF:
            buf.pop(0)
            continue

        idx = buf[1]
        cls_id = buf[2]
        cnt = buf[3]

        # 去重: 同一个idx只处理一次
        if idx != last_idx:
            last_idx = idx
            if cls_id == 0xFF:
                print(f"航点{idx}: 无动物")
            else:
                name = ANIMALS[cls_id]
                print(f"航点{idx}: {name} × {cnt}")

        buf = buf[5:]
```

## 六、上行链路（地面站 → Pi）

地面站需要向树莓派发送 **禁飞区坐标**。

### 6.1 上行帧格式

```
字节0    字节1    字节2    字节3   字节4   字节5   字节6   字节7
 AA      A+0xA0   B+0xB0   A+0xA0  B+0xB0  A+0xA0  B+0xB0   FF
0xAA     0xA?     0xB?     0xA?    0xB?    0xA?    0xB?    0xFF
        └── 禁飞区1 ──┘  └── 禁飞区2 ──┘  └── 禁飞区3 ──┘
```

| 字节 | 含义 |
|------|------|
| 0 | 帧头 `0xAA` |
| 1 | 禁飞区1的A坐标：`A值 + 0xA0`（如 A6 → `0xA6`） |
| 2 | 禁飞区1的B坐标：`B值 + 0xB0`（如 B3 → `0xB3`） |
| 3 | 禁飞区2的A坐标 |
| 4 | 禁飞区2的B坐标 |
| 5 | 禁飞区3的A坐标 |
| 6 | 禁飞区3的B坐标 |
| 7 | 帧尾 `0xFF` |

### 6.2 坐标范围

| 坐标 | 范围 | 物理含义 |
|------|------|---------|
| A | A1 ~ A9 | 9列（X方向） |
| B | B1 ~ B7 | 7行（Y方向） |

### 6.3 地面站发送示例

```python
# 禁飞区: A6B3, A5B3, A5B4
def send_forbidden_zones(ser, zones):
    """
    zones: [("A6", "B3"), ("A5", "B3"), ("A5", "B4")]
    """
    frame = [0xAA]
    for a_str, b_str in zones:
        a = int(a_str[1:])  # "A6" → 6
        b = int(b_str[1:])  # "B3" → 3
        frame.append(a + 0xA0)
        frame.append(b + 0xB0)
    frame.append(0xFF)
    ser.write(bytes(frame))
```

## 七、坐标映射（供UI开发参考）

### 7.1 格子编号 → 物理位置

```
内部坐标系:
  x ∈ [0,8], y ∈ [0,6]     (0,0) = 最右下角 (A9,B1)
  物理: rx = -x × 0.5 (米)
        ry =  y × 0.5 (米)

A-B映射:
  A → 9 - x    (A1→x=8, A9→x=0)
  B → y + 1    (B1→y=0, B7→y=6)

航点序号(waypoint_idx) ↔ 格子:
  ix = waypoint_idx 按路径顺序对应的内部 x
  iy = waypoint_idx 按路径顺序对应的内部 y
  A = 9 - ix, B = iy + 1
```

## 八、双向通信架构总览

```
┌──────────────────────────────────────────────────┐
│ 地面站                                            │
│                                                  │
│  下行接收 ← ttyS7 @115200 ← AA idx cls cnt FF    │
│  上行发送 → ttyS7 @115200 → AA A+0xA0 B+0xB0...FF│
│                                                  │
│  显示:                                            │
│    - 实时进度条 (waypoint_idx)                    │
│    - 检测结果 (cnt=1时弹出cls)                    │
│    - 禁飞区标记 (上行发送后)                       │
└──────────────────┬───────────────────────────────┘
                   │ UART
┌──────────────────┴───────────────────────────────┐
│ 树莓派 (Pi)                                       │
│                                                  │
│  Lprotocol.py:                                    │
│    Serial_dmz  → listen_dmz() 接收禁飞区          │
│                → send_dmz()   发送进度+结果        │
│                                                  │
│  Mission_GPT.py:                                  │
│    navigate()       → 每帧写 se_dmz[1] = idx      │
│    _detect_accept() → 写 se_dmz[2..3] = cls,cnt   │
└──────────────────────────────────────────────────┘
```
