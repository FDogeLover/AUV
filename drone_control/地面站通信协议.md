# 地面站通信协议说明 v2.0

## 一、物理层

| 参数 | 值 |
|------|-----|
| 接口 | UART 串口 |
| 波特率 | 115200 bps |
| 数据位 | 8 |
| 校验位 | 无 |
| 停止位 | 1 |
| 流控 | 无 |
| Pi端设备 | `/dev/ttyS7` |
| 发送频率 | **100Hz**（每10ms一帧） |
| 帧格式 | 二进制定长 **5 字节** |

---

## 二、帧格式

```
字节0     字节1          字节2       字节3       字节4
 AA     waypoint_idx   animal_cls   animal_cnt    FF
0xAA      0~255          0~255       0~255      0xFF
```

| 字节 | 名称 | 类型 | 说明 |
|------|------|------|------|
| 0 | 帧头 | u8 | 固定 `0xAA`，用于帧同步 |
| 1 | `waypoint_idx` | u8 | 当前航点序号，范围 0~255 |
| 2 | `animal_cls` | u8 | 动物类别（见下表） |
| 3 | `animal_cnt` | u8 | 动物数量，`0`=飞行中/无新结果，`≥1`=有新结果 |
| 4 | 帧尾 | u8 | 固定 `0xFF`，用于帧校验 |

---

## 三、动物类别编码

| 值 | 含义 |
|----|------|
| 0 | tiger 虎 |
| 1 | wolf 狼 |
| 2 | monkey 猴 |
| 3 | peacock 孔雀 |
| 4 | elephant 象 |
| 0xFF | 无动物 |

**注意**：`cls` 只在 `cnt ≥ 1` 时有效。`cnt = 0` 时忽略 `cls` 字段。

---

## 四、发送时序与状态解读

### 核心机制：AA/FF始终有效 + 哨兵值区分飞行/检测

```
初始:   [AA, 0, FF, 0, FF]     ← AA/FF 始终点亮
飞行中:  [AA, idx, FF, 0, FF]   ← cls=FF+cnt=0 = 飞行哨兵
检测完成: [AA, idx, cls, cnt, FF] ← cnt≥1 = 检测结果
下一帧:  [AA, idx, FF, 0, FF]   ← navigate()自动复位哨兵
```

**关键**：`AA=0xAA` 和 `FF=0xFF` 永不关闭，`cls=0xFF+cnt=0` 区分"飞行中"和"有结果"。

### 4.1 起飞前 / 飞行中

```
帧: AA 00 FF 00 FF    ← 起飞前
    AA 01 FF 00 FF    ← 飞往第1个航点
    AA 02 FF 00 FF    ← 飞往第2个航点
    AA 05 FF 00 FF    ← 飞越第5个航点（已检测→跳过）
    ...
```

地面站：`cnt=0` → 只更新进度条 `idx`，不处理结果。

### 4.2 检测完成 — 地面站唯一关心的时刻

每个航点检测完成后，`cls/cnt` 仅被写入一帧：

```
时间 →
                  ↓ _detect_accept(3号点, tiger x2)
帧:  AA 02 FF 00 FF  AA 03 00 02 FF  AA 04 FF 00 FF  AA 05 FF 00 FF  ...
      ① 飞行中        ② 唯一结果帧！     ③ nav复位哨兵    ④ 继续飞行

地面站:
  ①②③④ 全部收到 (AA/FF始终有效)
  ① cnt=0 → 忽略
  ② cnt=2≥1 → 处理！记录 idx=3, tiger x2
  ③ cnt=0 → 忽略
  ④ cnt=0 → 忽略
```

### 4.3 完整时序示例

```
航点0(起点)    航点1(飞行)    航点2(检测)    航点3(飞越)    航点4(检测)
AA 00 FF 00    AA 01 FF 00    AA 02 01 03   AA 03 FF 00    AA 04 FF 01
                                ↑ monkey x3                 ↑ 无动物
```

地面站处理：
| 帧 | cnt | 动作 |
|-----|-----|------|
| `AA 02 01 03 FF` | 3≥1 | idx=2, wolf x3 → 处理 |
| `AA 04 FF 01 FF` | 1≥1 | idx=4, 无动物 → 处理 |
| 其他 | 0 | 更新进度条 idx |

### 4.4 地面站去重逻辑

```python
last_idx = -1     # 上次处理的航点号

if cnt >= 1:                      # ← 只处理有结果的帧
    if idx != last_idx:            # ← 同一idx只处理一次
        # ... 显示结果 ...
        last_idx = idx
else:
    # cnt=0, 更新进度条 idx
    progress = idx / total
```

## 五、地面站接收伪代码

```python
import serial

ANIMALS = ["虎", "狼", "猴", "孔雀", "象"]
ser = serial.Serial("/dev/ttyS7", 115200, timeout=0.05)

buf = bytearray()
last_idx = -1     # 已处理的航点号，去重用

while True:
    buf.extend(ser.read(1))
    while len(buf) >= 5:
        if buf[0] != 0xAA or buf[4] != 0xFF:
            buf.pop(0)
            continue

        idx = buf[1]
        cls_id = buf[2]
        cnt = buf[3]

        if cnt >= 1:
            # 有检测结果
            if idx != last_idx:
                last_idx = idx
                if cls_id == 0xFF:
                    print(f"航点{idx}: 无动物")
                else:
                    name = ANIMALS[cls_id]
                    print(f"航点{idx}: {name} x{cnt}")
        else:
            # cnt=0: 飞行中，只更新进度
            pass  # UI: progress_bar = idx / total

        buf = buf[5:]
```

## 六、上行链路（地面站 → Pi）

地面站需要向树莓派发送 **禁飞区坐标**。

### 6.1 上行帧格式

```
字节0    字节1    字节2    字节3   字节4   字节5   字节6   字节7
 AA      A+0xA0   B+0xB0   A+0xA0  B+0xB0  A+0xA0  B+0xB0   FF
0xAA     0xA?     0xB?     0xA?    0xB?    0xA?    0xB?    0xFF
        └── 禁飞区1 ──┘  └── 禁飞区2 ──┘  └── 禁飞区3 ──┘
```

| 字节 | 含义 |
|------|------|
| 0 | 帧头 `0xAA` |
| 1 | 禁飞区1的A坐标：`A值 + 0xA0`（如 A6 → `0xA6`） |
| 2 | 禁飞区1的B坐标：`B值 + 0xB0`（如 B3 → `0xB3`） |
| 3 | 禁飞区2的A坐标 |
| 4 | 禁飞区2的B坐标 |
| 5 | 禁飞区3的A坐标 |
| 6 | 禁飞区3的B坐标 |
| 7 | 帧尾 `0xFF` |

### 6.2 坐标范围

| 坐标 | 范围 | 物理含义 |
|------|------|---------|
| A | A1 ~ A9 | 9列（X方向） |
| B | B1 ~ B7 | 7行（Y方向） |

### 6.3 地面站发送示例

```python
# 禁飞区: A6B3, A5B3, A5B4
def send_forbidden_zones(ser, zones):
    """
    zones: [("A6", "B3"), ("A5", "B3"), ("A5", "B4")]
    """
    frame = [0xAA]
    for a_str, b_str in zones:
        a = int(a_str[1:])  # "A6" → 6
        b = int(b_str[1:])  # "B3" → 3
        frame.append(a + 0xA0)
        frame.append(b + 0xB0)
    frame.append(0xFF)
    ser.write(bytes(frame))
```

## 七、坐标映射（供UI开发参考）

### 7.1 格子编号 → 物理位置

```
内部坐标系:
  x ∈ [0,8], y ∈ [0,6]     (0,0) = 最右下角 (A9,B1)
  物理: rx = -x × 0.5 (米)
        ry =  y × 0.5 (米)

A-B映射:
  A → 9 - x    (A1→x=8, A9→x=0)
  B → y + 1    (B1→y=0, B7→y=6)

航点序号(waypoint_idx) ↔ 格子:
  ix = waypoint_idx 按路径顺序对应的内部 x
  iy = waypoint_idx 按路径顺序对应的内部 y
  A = 9 - ix, B = iy + 1
```

## 八、双向通信架构总览

```
┌──────────────────────────────────────────────────┐
│ 地面站                                            │
│                                                  │
│  下行接收 ← ttyS7 @115200 ← AA idx cls cnt FF    │
│  上行发送 → ttyS7 @115200 → AA A+0xA0 B+0xB0...FF│
│                                                  │
│  显示:                                            │
│    - 实时进度条 (waypoint_idx)                    │
│    - 检测结果 (cnt=1时弹出cls)                    │
│    - 禁飞区标记 (上行发送后)                       │
└──────────────────┬───────────────────────────────┘
                   │ UART
┌──────────────────┴───────────────────────────────┐
│ 树莓派 (Pi)                                       │
│                                                  │
│  Lprotocol.py:                                    │
│    Serial_dmz  → listen_dmz() 接收禁飞区          │
│                → send_dmz()   发送进度+结果        │
│                                                  │
│  Mission_GPT.py:                                  │
│    navigate()       → 每帧写 se_dmz[1] = idx      │
│    _detect_accept() → 写 se_dmz[2..3] = cls,cnt   │
└──────────────────────────────────────────────────┘
```

| 版本 | 日期 | 变更 |
|------|------|------|
| v1.0 | — | 6字节帧：`AA A+0xA0 B+0xB0 class count FF`，固定坐标 `(A9,B1)` |
